## 1. Krug 2013 (krug.com/en-gb/champagne/krug-2013)

**총 높이 ~8,600px. 세리프 럭셔리·크림 페이퍼 톤.**

### 레이아웃 골격
- **좌우 세로 텍스트 네비**: 좌측 세로 `MENU`, 우측 세로 `WHERE TO FIND KRUG` (90° 회전, 화면에 고정). 긴 페이지를 붙잡는 앵커.
- **얇은 hairline 프레임**: 콘텐츠를 가는 선 박스로 감싸 "문서/증서" 느낌.
- **챕터링**: 우하단에 필기체로 `Part 1`, `Part 2`… — 페이지를 장(章)으로 나눔.

### 섹션 구성
1. **히어로** — 좌: 큐베 소개 텍스트 + `Cuvée [연도 ▾]` 선택 드롭다운 / 중앙~우: **대형 병 이미지 단독 부유**(바닥 그림자) / 우하단: 품종 데이터(pinot noir 41%·chardonnay 38%·meunier 21%) + `previous / 2013`.
2. **`A word from` THE CELLAR MASTER** — **소문자 이탤릭 리드인 + 대형 세리프 헤드**. 셀러마스터 인물 사진 풀블리드 + 인용구 + `KRUG iD` 조회 블록.
3. **TASTING NOTES / FOOD PAIRING** — 텍스트 2블록(감각 서술).
4. **3열 아이콘 카드** — `SERVING TEMPERATURE` / `THE JOSEPH GLASS` / `THE INFLUENCE OF TIME`. 각 아이콘 + `Note:` 라벨 + 짧은 설명 + `LEARN MORE`.
5. **MUSIC PAIRINGS** — 대형 세리프 헤드 + 음악 플레이어(그 해를 위한 곡).
6. **WHERE TO ENJOY KRUG** — 앰버서더(레스토랑) 안내.
7. **Newsletter + 대형 4열 푸터.**

### 타이포·컬러
- 디스플레이 **세리프**(Apolline, 대형 uppercase) vs 본문 **산세리프**(Gotham, 14px). 극단적 크기 대비.
- 배경 크림 `rgb(241,239,235)`, 액센트 버건디. 필기체(Cuvée·Part)로 손맛.

### 핵심 통찰
> **제품 고유 콘텐츠는 히어로 + 셀러마스터 코멘트 + 테이스팅뿐. 나머지(음악·앰버서더·뉴스레터)는 전 제품 공통 재사용.** 개별화는 **Krug iD**(병별 6자리 코드 조회)가 페이지 밖에서 담당한다. → 제품 페이지를 길게 만들 이유가 적다.

## 2. Dom Pérignon Plénitude 2 (domperignon.com/product/plenitude-2)

**총 높이 ~9,400px. 모던·산세리프·극단적 여백·영상 중심.**

### 레이아웃 골격
- **초미니멀 헤더**: `MENU` / 로고 / `STORES` 셋뿐.
- **스티키 탭 네비**(스크롤 중 하단 고정): `[PLÉNITUDE 2 ▾]` 제품 드롭다운 + `INTRODUCTION` · `VINTAGES` · `VINCENT CHAPERON'S WORDS` · `CHEF PORTRAIT`. 긴 페이지를 탭으로 점프.
- **극단적 여백**: 섹션 사이 흰 공간이 화면 절반 이상. 요소 하나에 온전히 집중.

### 섹션 구성
1. **히어로** — 풀블리드가 아니라 **여백 큰 중앙 영상 배너**(가로 와이드, 다크 무음 루프). 위 아이브로우 `PLÉNITUDE 2` + 대형 산세리프 슬로건 `ELEVATED WITH TIME`.
2. **풀블리드 매크로 이미지** — 병 입구를 들여다본 골드톤 추상 컷. 텍스트 없음.
3. **중앙 짧은 설명** — 아이브로우 소문자 + **대형 산세리프 헤드 3줄**(제품 정의) + 작은 회색 설명 3줄. 이 지점에서 스티키 탭 등장.
4. **VINTAGES** — 좌: 병 라벨 매크로 풀블리드 / 우: 빈티지 탭(`2008 · 2006 · 2004 · 2003`) + 병 이미지 + 짧은 설명 + `DISCOVER THE VINTAGE`.
5. 이후 **Vincent Chaperon's words / Chef portrait** — 인물·영상 섹션 연속.

### 타이포·컬러
- **단일 산세리프**(GT America류)로 전 페이지. 세리프는 로고만.
- 라이트 배경 `rgb(247,247,247)` + **다크 이미지/영상**의 강한 대비. 액센트 색 거의 없음.
- 크기 위계가 의외로 좁음(헤드도 과도하지 않음) — **위계의 최상단은 타이포가 아니라 영상**.

### 핵심 통찰
> **"영상·이미지가 말하고, 텍스트는 최소"**. 제품 정의는 중앙 3줄이면 끝. 나머지는 빈티지 아카이브·인물 서사로, 스크롤이 곧 **한 편의 필름**. 시간(P1/P2/P3)을 제품화한 브랜드답게 "elevated with time"이 전 페이지를 관통.

## 3. 두 페이지의 공통 문법 (배울 것)

| 요소 | Krug | Dom Pérignon | 공통 원칙 |
|---|---|---|---|
| 여백 | 큼 (hairline 프레임 안) | 극단적 (섹션 사이 빈 화면) | **여백이 격을 만든다** |
| 주인공 | 대형 병 + 인물 사진 | 영상 + 매크로 이미지 | **이미지가 콘텐츠, 텍스트는 각주** |
| 헤드 | 대형 세리프 | 대형 산세리프 | **섹션마다 한 방짜리 대형 헤드** |
| 긴 페이지 탐색 | 세로 텍스트 네비 + Part 챕터 | 스티키 탭 네비 | **앵커/탭으로 스크롤을 붙잡는다** |
| 제품 데이터 | 품종 % 한 줄 | 빈티지 연도 탭 | **데이터는 짧게, 절제** |
| CTA 언어 | LEARN MORE / KRUG iD | DISCOVER / STORES | **판매어 없음** |
| 개별화 장치 | Krug iD(페이지 밖) | 빈티지 아카이브 | **제품 고유성을 다루는 방식이 있다** |

**공통 결론:** 둘 다 **"제품 페이지는 짧게, 브랜드 경험은 공통 재사용"**. 제품 간 차이가 작아서(빈티지=그 해 기후 정도) 가능한 전략.

## 4. 우리는 어떻게 다른가 — 방향성

### 결정적 차이: 우리는 제품마다 고유한 "기록"이 있다

Krug·DP가 제품 페이지를 짧게 가는 건 **제품 간 차이가 작기 때문**이다. 우리는 정반대다 (북극성 §3·§4-①):

> **모든 병이 자신이 살아낸 시간의 완전한 기록과 함께 온다.**

- En Lieu Sûr와 다음 큐베는 **다른 좌표·다른 입수/인양일·다른 수온 그래프·다른 따개비**를 가진다.
- Krug iD가 "제작 스토리"라면, 우리 NFC 기록 카드는 **그 병이 살아낸 시간의 측정 기록** — 페이지 밖으로 뺄 게 아니라 **페이지의 본체**다.

**→ 그러므로: Krug/DP처럼 제품 페이지를 짧게 줄이면 우리 강점을 버리는 것.** 대신 두 페이지의 **컴포지션(여백·절제·대형 헤드·이미지 주인공·탭 네비)**만 배우고, 콘텐츠는 **이 병만의 dossier**로 채운다.

### 우리 상세페이지 원칙 (도출)

1. **여백과 절제** (공통) — 지금까지 "AI틱"했던 원인 = 밀도 과다·작은 이미지. 요소를 줄이고 여백을 키운다.
2. **이미지가 주인공** (DP) — 입수·인양·생산지·따개비 실사를 **크게(풀블리드/절반)**, 텍스트는 각주로. 작은 박스 금지.
3. **대형 헤드 한 방** (공통) — 섹션마다 작은 mono eyebrow 대신 **대형 헤드**(Cormorant 한글은 Noto 300 대형). "OBSERVATION" 같은 라벨을 크게.
4. **스티키 탭 네비** (DP) — 긴 페이지를 `관측 · 구성 · 기록` 탭으로 점프. Krug의 `Part` 챕터링도 참고.
5. **데이터는 짧게, 그러나 고유하게** — Krug 품종 한 줄처럼 절제하되, 우리는 **제품마다 다른 기록**(입수/인양/좌표/그래프)이 차별점이므로 이건 유지.
6. **다크→라이트 · Abyssal Amber · 3-Font** — 우리 정체성 유지. DP의 "라이트+다크 이미지 대비"는 우리 명암 교차와 이미 정합.

### 우리만의 구조 (제안 골격)

```
[히어로]        병 오브제(현재 유지) 또는 12월 인양 영상. 큐베명 + "365일을 보내고 돌아왔습니다"
                — DP식: 여백 크게, 한 줄 슬로건.
   ↓ (스티키 탭 등장: 관측 · 구성 · 기록)
[관측]          풀블리드 인양/입수 실사 크게 + 데이터는 각주 오버레이 (DP 매크로 + 짧은 설명)
[구성]          프랑스 생산지 이미지 크게 + 스펙 절제 (Krug 3열 카드처럼 정보 최소)
[기록]          따개비 매크로 크게 + RECORD CARD (= 우리의 Krug iD, 페이지 안에)
[마무리]        다음 아카이브 연결 + 문의 + 모토 서명
```

핵심: **Krug/DP의 "적은 요소·큰 여백·큰 이미지"를 따르되, 그 큰 이미지·데이터가 "제품마다 다른 기록"이라는 점이 우리만의 것.**

## 5. 확정 구조 — "한 병의 전기(傳記)" (2026-07-03 · **CEO 승인 완료**)

> ✅ **2026-07-03 사용자 승인.** 이 구조로 Paper 시안 완성. 다음: 모바일 시안 → 코드 구현.

> Krug/DP는 "제품 페이지"를 만들지만, 우리 페이지는 **그 병의 전기**다. 구조가 마케팅 섹션(관측/구성/기록 라벨)이 아니라 **시간의 구조**를 가진다.

```
1 HERO       (유지) 병 오브제 + "365일을 보내고 돌아왔습니다"
2 PROLOGUE   "샴페인은 샹파뉴가 만들고,"   — 라이트 · 프랑스 · 낮
             Venteuil 이미지 와이드 + 스펙 한 줄(절제)
3 THE YEAR   "시간은 남해가 씁니다."       — 다크 · 남해 · 밤
             입수 풀블리드 → 관측 일지 엔트리(D001~D365 날짜별 몇 줄)
             → 수온 곡선(계절 주석) → 인양 풀블리드
4 THE RECORD 따개비 매크로 풀블리드(무언 브리더, DP식)
             → "비우고 나도, 기록은 남습니다" + RECORD CARD(NFC)
5 EPILOGUE   맡아둠 + 문의 + 다음 아카이브 + 모토
```

**시그니처 장치:**
1. **한 문장의 이등분** — 승인 카피 "샴페인은 샹파뉴가 만들고, 시간은 남해가 씁니다"를 프랑스 장·바다 장의 제목으로 분할. 스크롤이 문장을 완성.
2. **관측 일지 엔트리** — `D 092 · 가장 차가운 날 · 7.9°C` 식 날짜 스탬프 로그. §7-3 "측정은 헌신의 형식"을 형식으로 증명. 어떤 샴페인 하우스도 없는 콘텐츠. (수치는 12월 실측 전 시드)
3. **장 제목 = 손글씨 서체(J1950)** — 랜딩 헤드라인과 동일 DNA, "바다가 쓴 원고"와 서체 일치. Krug 세리프/DP 산세리프에 없는 우리 목소리.
4. (코드 단계) **D-카운터 스크롤 진행** — 스크롤에 따라 D001→D365 카운트되는 코너 칩 + 스티키 탭(서문·일지·기록).

## 6. 다음 단계

1. 이 구조로 Paper 시안 재설계 — 여백↑·풀블리드 이미지·손글씨 장 제목. 히어로 유지.
