# 랜딩페이지 개선 분석 보고서

> 작성일: 2026-03-16
> 기반: 외부 제안서 + 마케팅 심리학 + 카피라이팅 프레임워크 + 브랜드 기준서 교차 분석

---

## 핵심 진단

> "방문자가 3초 안에 이해해야 하는 핵심 메시지가 약하다"

**Curse of Knowledge** (지식의 저주) 관점에서 정확한 지적.
브랜드 내부에서는 "해저 숙성 샴페인"이 자명하지만, 첫 방문자는 "두 개의 떼루아"가 무슨 뜻인지 모른다.

단, **적용 방식에서 럭셔리 브랜드의 특수성**을 반드시 고려해야 한다.

### 핵심 메시지 (합의)

"프랑스 샹파뉴에서 태어나 한국의 바다에서 숙성된 샴페인"

---

## 섹션별 분석

### 1. HERO — 부분 수용

**제안**: "한국 바다에서 숙성된 샴페인"으로 직접 전달
**현재**: "두 개의 떼루아" + "한국 바다가 숙성한 샴페인"

| 관점 | 판단 |
|------|------|
| **AIDA** | 제안이 맞음 — Attention 단계에서 "무엇인지"가 먼저 와야 함 |
| **럭셔리 톤** | 제안이 너무 설명적 — Krug/Dom Pérignon은 hero에서 제품을 설명하지 않음 |
| **Framing Effect** | 현재 "두 개의 떼루아"는 프레이밍이 강함 — 단순 설명보다 브랜드 세계관 구축에 유리 |

**추천 적용법**: 히어로 구조는 유지하되, 서브카피에서 명확성 보강

```
메인: 두 개의 떼루아 (유지)
서브: 프랑스 샹파뉴에서 태어나, 한국 바다에서 숙성된 샴페인 (제안 수용)
     → 현재 서브 "한국 바다가 숙성한 샴페인"보다 구체적
```

**CTA 추가**: 현재 히어로에 CTA 없음 — BJ Fogg 모델(Prompt 부재)
- 브랜드 톤: "컬렉션 발견하기" 또는 "해저 숙성의 시간으로"
- "컬렉션 보기"는 너무 직접적, "구매하기"는 브랜드 기준 위반

---

### 2. TWO TERROIRS — 수용 불필요

제안의 카피가 현재 Observation 섹션과 거의 동일한 역할을 수행 중.
별도 섹션 추가 불필요.

---

### 3. SEA AGING 설명 섹션 (신규) — 조건부 수용

**마케팅 심리학 근거**:
- **Jobs to Be Done**: 방문자의 핵심 질문은 "왜 바다에서?"임. 이걸 답하지 않으면 나머지가 공허함
- **Authority Bias**: 과학적 근거(온도, 수압, 해류)를 제시하면 신뢰 구축
- **Confirmation Bias**: "해저 숙성 = 더 좋은 것"이라는 믿음을 만들어줘야 함

**문제점**: 제안된 카피가 너무 교과서적. "왜 바다에서 숙성할까요"는 FAQ 톤이지 럭셔리 톤이 아님.

**추천 적용법**: 현재 Observation 섹션을 강화하는 방향으로 흡수

```
현재 Observation이 이미 수압/해류/파도를 다루고 있음.
→ "안정적인 온도", "자연 수압", "미세한 해류" 3가지 포인트를
   Observation 내 시각적 데이터 포인트로 추가.
→ 별도 섹션 신설보다 기존 섹션 보강이 페이지 길이 관리에 유리.
```

---

### 4. COLLECTION — 카피 보강 수용

**Scarcity / Urgency**: "50병 한정"은 강력한 희소성 신호. 현재도 일부 적용 중이지만 더 강조 가능.

**추천 적용법**:
- 각 큐베 카드에 생산 수량 더 눈에 띄게 표시
- "수심 50m에서 숙성된" 같은 구체적 숙성 맥락 추가
- "sold out" 표시는 이미 있음 — Social Proof로 잘 작동 중

---

### 5. THE MAKER — 수용

**Authority Bias** + **Liking/Similarity**: 생산자의 전통과 세대 이야기는 신뢰와 감정 연결 모두 제공.

현재 카피 "바다가 선택할 수 있는 가장 좋은 샴페인"은 좋지만, **"세대를 이어온"** 맥락을 보강하면 더 강력.

**추천 적용법**:
- 세대 수, 설립 연도를 더 시각적으로 강조
- "1888년부터 6세대"는 이미 있음 → 폰트 크기/위치로 가시성 높이기

---

### 6. OCEAN CELLAR — 스토리 보강 조건부 수용

**Peak-End Rule**: "어둠, 수압, 해류" 세 키워드는 강렬한 피크 모먼트를 만들 수 있음.

하지만 현재 Ocean Cellar 섹션은 **멤버십** 섹션임.
제안의 "바다 속 셀러" 스토리는 Observation에 더 가까움.

**추천**: Ocean Cellar 멤버십은 유지하고, "해저 케이지" 비주얼 스토리는 Observation 섹션의 이미지/영상으로 흡수.

---

### 7. LIVING DATA — 설명 추가 수용

현재 "지금, 바다의 기록"이라는 프레이밍이 좋지만, 맥락 한 줄 추가하면 효과적.

**추천**: 서브카피에 "각 컬렉션의 숙성 환경을 실시간으로 기록합니다" 추가.

---

### 8. NFC EXPERIENCE (신규) — 강력 추천

**마케팅 심리학 근거**:
- **IKEA Effect**: 직접 터치해서 정보를 확인하는 행위 → 소유감 증가
- **Endowment Effect**: NFC로 "나만의 병 기록"을 보는 순간 애착 형성
- **Contrast Effect**: 일반 샴페인과의 차별화가 극대화

**이것은 가장 실행 가치가 높은 제안**.

**추천 적용법**:
- 런칭 시점에 별도 섹션으로 추가하거나,
- Living Data 섹션 하단에 "병을 터치하면 바다의 기록이 열립니다" 티저로 배치.
- 현재 단계에서는 와이어프레임/컨셉 수준으로 준비.

---

### 9. MEMBERSHIP — 현재 유지

이미 잘 구성됨. 제안 내용과 현재 구현이 거의 동일.

---

### 10. VISUAL — 가장 중요한 제안

> "그래픽 중심 → 이미지 중심"

- **Mere Exposure Effect** + **Availability Heuristic**: 실제 해저 사진/영상이 있으면 "진짜 바다에서 숙성한다"는 믿음이 즉각 형성됨
- 현재 플레이스홀더 이미지로는 이 효과를 얻을 수 없음
- **이것은 카피보다 더 중요한 개선 포인트**

필수 이미지 목록:
- 해저 케이지
- 잠수 장면
- 해저에 있는 병
- 샴페인 병 클로즈업
- 코르크 / 기포 디테일

---

### 11. 브랜드 핵심 문장 — 수용

사이트 곳곳에 반복 사용할 앵커 문장:

```
Option A: 프랑스 샹파뉴에서 태어나, 한국 바다에서 숙성된 샴페인
Option B: 두 개의 떼루아가 만든 샴페인 — Champagne × Korean Sea
Option C: 바다가 완성한 샴페인
```

**Mere Exposure Effect**에 의해 반복 노출 시 브랜드 인식 강화.

## 핵심 원칙: 브랜드 기준서와의 균형

이 제안서의 방향은 **"명확성 ↑"**이고, 현재 사이트는 **"예술성 ↑"**이다.

럭셔리 브랜드에서 정답은 **둘 다**:
- **Above the fold**: 명확성 우선 (3초 이해)
- **스크롤 이후**: 예술성으로 세계관 구축
- **판매 언어 절대 금지** 원칙은 유지 ("구매" → "발견", "결제" → "경험 시작")
- **"맛", "향", "풍미"** 등 직접적 감각 단어 사용 금지 유지

1. 히어로 서브카피: "한국 바다가 숙성한 샴페인" → "프랑스 샹파뉴에서 태어나, 한국 바다에서 숙성된 샴페인"
2. 히어로 CTA 버튼 추가: "컬렉션 발견하기"
3. Living Data 맥락 한 줄 추가

### Phase 2 — 디자인 보강 (1-2주)
4. Collection 큐베 카드 희소성 표시 강화
5. Observation 섹션 과학적 근거 3포인트 추가
6. The Maker 세대/연도 정보 시각적 강조

7. 실제 해저 촬영 이미지/영상 교체
8. NFC 체험 섹션 신설
