## 1. 분석 배경

### 1.1 현재 상태

- **사이트 구조**: 단일 페이지(`/`), 7개 섹션이 앵커(`#`)로 연결
- **섹션 순서**: Hero → Bridge → Observation → Sea Log → Tasting → Collection → The Maker → Ocean Circle → Partnership
- **별도 페이지**: 없음 (`/welcome`, `/sea-log`, `/preorder` 등 미존재)
- **UTM 추적**: 없음
- **플로팅 CTA**: 없음
- **OG 카드**: 정적 (동적 데이터 미반영)

### 1.2 리포트 요약

바이럴 리포트는 10개 채널 × 4개 스턴트 × 웹사이트 페이지를 연결하는 채널별 아키텍처를 제안한다.

**핵심 제안:**
1. 멀티 페이지 전환: `/welcome`, `/sea-log`, `/about`, `/preorder`, `/membership`, `/partnership` 등 8개+ 독립 페이지
2. 바이럴 퍼널: TikTok/Reels → `/welcome`(3초 임팩트) → `/preorder` 빠른 전환
3. "Nothing Hidden" 메인 캠페인: 숙성 데이터 전면 공개로 투명성 차별화
4. 플로팅 CTA: 모든 페이지에 "프리오더" 하단 고정
5. 동적 OG 카드: 카카오톡 공유 시 매일 변하는 수온 데이터
6. UTM 추적: 채널별 유입 분석

## 2. Direction C 원안과의 괴리 — 근본 원인 발견

### 2.1 핵심 발견

**현재 사이트가 Direction C 원안에서 이탈한 것이 모든 문제의 근본 원인이다.**

Direction C(`musedemaree-direction-c-final.md`)는 바이럴 리포트와 마케팅 피드백이 지적한 문제들의 해답을 이미 가지고 있었다. 그러나 구현 과정에서 원안이 변형되었다.

### 2.2 Direction C vs 현재 사이트 비교

| 항목 | Direction C 원안 | 현재 사이트 | 괴리 |
|------|-----------------|------------|------|
| **히어로 카피** | "바다에서 숙성한 샴페인." (한 줄, USP 직격) | "하나의 샴페인 / 두 개의 떼루아" | **USP 실종** — "떼루아"는 업계 용어, 첫 방문자에게 전달력 없음 |
| **히어로 구조** | Beat 1(정적 선언) → Beat 2(12초 영상, 입수 과정) | 배경 이미지 + 영상 (서사 불분명) | **2비트 구조 미구현** |
| **§1 해저(Sea Log)** | 감각 카피 + 데이터 교차: "이 압력이 만드는 기포를, 잔에서 확인하게 됩니다" | 6개 지표 숫자만 나열 | **감각 연결 없음** |
| **데이터 구조** | 핵심 2개(수압, 수온)만 본문 노출 + /sea-log 별도 페이지 | 6개 전부 본문에 | 초점 분산 |
| **증명 사진** | 입수/인양/해저 실제 사진 필수 (서사의 물증) | 이미지 1장 (o2.webp) | **신뢰 근거 부족** |
| **전체 구조** | 4섹션 압축 — 19초에 제품 도달 | 7+섹션 — 도달 시간 과다 | **제품까지 너무 멀다** |
| **CTA** | 감정 정점(§2 클라이맥스)에 "컬렉션 살펴보기" 딱 하나 | CTA 거의 없음 | **전환 장치 부재** |
| **The Maker** | /makers 별도 페이지 분리 | 메인 페이지에 인라인 | 메인 서사 과부하 |
| **감정 곡선** | 선언 → 몰입 → 반전(데이터) → 상승 → 클라이맥스 → 착지 | 평탄한 나열 | **감정 설계 부재** |

### 2.3 Direction C의 감각 + 데이터 교차 구조 (원안)

Direction C는 Sea Log를 "반전 장치"로 설계했다:

```
§1 해저 — 감각 + 데이터 교차

요소 1: Pression
  "수압이 기포를 다듬습니다. 더 조밀하게. 더 섬세하게."
  3.97 atm
  "이 압력이 만드는 기포를, 잔에서 확인하게 됩니다."

요소 2: Courant
  "해류가 온도를 지킵니다. 산미는 더 선명해집니다."
  11.2°C
  "첫 모금의 선명함은 이 온도에서 시작됩니다."

요소 3: Silence
  "완전한 어둠 속에서 시간만이 일합니다."
  (데이터 없음 — 침묵에는 숫자가 없다)
```

이 구조가 마케팅 피드백이 원하는 것 그 자체:
> "고객이 잔을 기울일 때 '아, 이 부드러운 기포가 그 4기압의 수압 덕분이구나'라고 연상하게 만드는 것"

### 2.4 Direction C의 감정 곡선

```
감정
  ↑
  │              ★ "첫 모금에서 다릅니다" (CTA 위치)
  │             ╱╲
  │            ╱  ╲ Collection
  │     Sea  ╱    ╲
  │     Log ╱      ╲
  │       ╱         ╲
  │  ───╱  §1 해저    ╲── §3 Ocean Cellar
  │ ╱                    ╲── §4 Partnership
  │╱  Beat 2 영상
  │
  │ Beat 1 선언
  ├──────────────────────────────→ 스크롤
```

### 2.5 결론: 새로 만들 것이 아니라 원안으로 돌아가야 한다

바이럴 리포트가 8개 페이지를 제안하고, 마케팅 피드백이 구조 변경을 요구하지만,
**가장 효과적인 1차 조치는 Direction C 원안에 재정렬(Realign)하는 것이다.**

Direction C가 이미 해결한 것:
- ✅ 히어로 USP ("바다에서 숙성한 샴페인")
- ✅ 데이터 + 감각 연결 (Pression/Courant/Silence)
- ✅ 증명 사진 필수 (입수/인양/해저)
- ✅ 감정 정점의 CTA ("컬렉션 살펴보기")
- ✅ /sea-log 독립 페이지 분리
- ✅ The Maker → /makers 분리
- ✅ 4섹션 압축 (19초에 제품)

Direction C에 없어서 추가로 필요한 것:
- UTM 추적 (바이럴 리포트)
- 동적 OG 카드 (바이럴 리포트)
- /welcome Entry Vestibule (바이럴 유입용, Phase 3)
- 하단 초대 바 (마케팅 피드백)

## 3. 핵심 진단: DTC 프레임워크를 럭셔리에 적용한 문제

리포트는 기술적으로 잘 설계되어 있으나, **DTC(Direct-to-Consumer) 그로스해킹 프레임워크를 럭셔리 브랜드에 그대로 적용**한 근본적 전제 문제가 있다.

### 2.1 전제 도전

| 관점 | 분석 |
|------|------|
| **타겟 불일치** | Primary 타겟은 40-50대 컬렉터형. TikTok 핵심 사용층이 아님. 리포트는 Tertiary(30-40대 얼리어답터)를 위한 인프라를 최우선으로 제안 |
| **브랜드 포지셔닝 충돌** | "비교하지 않습니다. 그저 존재할 뿐입니다" + "마실 수 있는 시간의 예술" ← 이 포지셔닝에 "3초 임팩트 랜딩 → 즉시 프리오더"는 양립 불가 |
| **레퍼런스 이탈** | Krug.com에는 `/welcome`이 없음. Hermès.com에 플로팅 "Buy Now"가 없음. 리포트의 구조는 DTC 브랜드(Casper, Warby Parker)에 적합하지 럭셔리에는 부적합 |

### 2.2 바이럴 ↔ 럭셔리, 양립 가능한가?

**가능하다. 단, 실행 방식이 완전히 달라야 한다.**

- **Mimetic Desire(모방적 욕망)**: 에르메스 버킨백은 수백만 명이 알지만 수천 명만 살 수 있다. 바이럴로 인지도를 높이되, 진입 장벽은 유지하는 것이 럭셔리의 방식
- **Scarcity Heuristic(희소성 휴리스틱)**: TikTok에서 100만이 봤는데 240병뿐 → 이 대비가 희소성을 극대화
- **결론**: 바이럴 자체는 좋다. 하지만 바이럴 "이후"의 경험이 럭셔리여야 한다

## 4. 마케팅 심리학 분석

### 3.1 `/welcome` 3초 랜딩의 심리적 문제

- **Peak-End Rule**: 첫 인상이 브랜드 인식을 결정. DTC 스타일 랜딩은 브랜드를 크라우드펀딩 제품처럼 느끼게 함
- **Contrast Effect**: TikTok → 갤러리 입구의 느낌이면 "특별한 곳에 왔다"는 인상. TikTok → 쇼핑몰 팝업이면 브랜드 훼손
- **대안**: `/welcome`은 3초 임팩트가 아닌 **"Entry Vestibule(진입 현관)"** — 갤러리 입구의 느낌

### 3.2 플로팅 CTA의 심리적 임팩트

- 럭셔리에서 friction(마찰)은 의도적 설계. 에르메스에서 버킨을 사려면 "여정"이 필요
- 상시 "프리오더" 버튼 = "이건 급하게 팔아야 하는 물건"이라는 신호
- **대안**: "바다의 원에 들어오세요"처럼 브랜드 언어로 전환된 미묘한 초대

### 3.3 "Nothing Hidden" 투명성 vs 럭셔리의 신비

리포트의 **가장 가치 있는 인사이트**이나, 프레이밍이 잘못되었다.

- ❌ "우리는 숨기지 않습니다" (Everlane식 = mass-premium)
- ✅ "바다가 기록하는 시간" (자연이 쓰는 일기 = luxury)
- "투명성"이 아니라 **"목격(Witness)"**으로 재프레이밍하면 브랜드 강화 수단이 됨

### 3.4 단일 서사 vs 멀티 진입점

- **AIDA Funnel**: 단일 페이지는 Attention → Interest → Desire → Action을 자연스럽게 따름
- **Commitment & Consistency**: 순차 스크롤 = 에스컬레이팅 커밋먼트 (각 스크롤이 마이크로 커밋먼트)
- **Theory of Constraints**: 지금 병목은 사이트 구조가 아니라 트래픽. 아직 존재하지 않는 트래픽을 위해 8개 페이지를 만드는 것은 premature optimization

## 5. 마케팅 담당자 피드백 분석

### 4.1 핵심 원칙

> **"럭셔리 마케팅의 핵심은 '설명'하지 않고 '증명'하는 것"**

### 4.2 피드백 요약

| 문제 | 진단 | 개선 방향 |
|------|------|----------|
| **USP 전달이 너무 늦고 약함** | 현재 히어로 "하나의 샴페인 / 두 개의 떼루아" — 5초 안에 "이게 뭐냐, 왜 특별하냐"가 안 꽂힘 | 첫 화면에서 "한국 바다에서 숙성된 샴페인"을 강하게 어필 |
| **"바다 숙성"이 컨셉처럼 보임** | 감각적 스토리는 있지만 "실제로 그렇게 한다"는 신뢰가 약함 | 실제 입수/인양 사진, 작업 과정 컷, 데이터 필수 |
| **전환 장치 부재** | "좋네" 하고 끝남. CTA 없음, 리드 수집 없음 | 럭셔리 언어로 된 전환 장치 + 이메일 수집 |
| **Sea Log가 핵심** | 수치가 과학 정보에 그치지 않고, 샴페인 경험과 연결되어야 함 | "4기압 → 부드러운 기포" 연상 구조 |

## 7. 히어로 문제 상세 분석

### 6.1 현재 상태

```
현재 히어로: "하나의 샴페인 / 두 개의 떼루아"
→ 스크롤 → 영상 재생 → 디졸브

현재 Observation: "수심 50미터. 빛이 사라진 곳에서 숙성이 시작됩니다."
               "3.98기압의 수압이 기포를 다듬고, 8°C의 해류가 온도를 지키고..."
```

**문제**: Observation의 카피가 USP를 정확히 전달하는데, 이것이 2번째 섹션에 있다. 첫 방문자는 히어로에서 "이게 뭔지" 파악하지 못하고 이탈할 수 있다.

### 6.2 개선 방향

히어로에서 **5초 안에 전달해야 하는 것**:
1. 이것은 **샴페인**이다
2. **바다에서 숙성**한다 (세계 유일)
3. **데이터로 증명**한다

마케팅 피드백의 스토리보드 예시:
> **"심해의 시간, 샴페인의 정점."**
> *(The Depth of Time. The Peak of Champagne.)*

## 8. Sea Log 개선 방향

### 7.1 현재 vs 개선

마케팅 피드백의 핵심: 숫자가 과학 정보에 그치지 않고, 고객이 잔을 기울일 때 연상하게 만들어야 한다.

```
현재:
  수온 11.2°C | 해류 2.34m/s | 수압 3.97atm
  (숫자만 나열)

개선:
  수온 11.2°C
  "일정한 저온이 숙성의 속도를 결정합니다"

  수압 3.97atm
  "이 압력이 기포의 밀도를 다듬습니다"

  해류 2.34m/s
  "병을 어루만지는 물결의 속도"
```

### 7.2 독립 페이지 `/sea-log`

메인 페이지의 Sea Log 섹션은 "요약"이고, `/sea-log` 독립 페이지는 "깊은 탐색"을 제공:
- 30일 추세 그래프
- 각 수치의 샴페인에 미치는 영향 상세
- 동적 OG 카드 (카카오톡 공유 — "오늘의 바다: 수온 11.1°C")

## 9. CTA 설계 — 럭셔리 언어

| 위치 | 리포트 제안 | 최종 방향 |
