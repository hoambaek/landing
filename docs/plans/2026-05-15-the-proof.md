## 0. 한 줄 요약

**한 페이지에 USP·증명·초대만 남긴다. Sea Log를 중심에 두고, 나머지는 비운다.**

> 럭셔리 마케팅의 핵심 — **'설명'하지 않고 '증명'한다.**
> Sea Log의 수치가 미래 첫 잔의 기포와 연결되는 순간, 이 랜딩은 성공한다.

## 3. 섹션별 최종 설계

### ① HERO — USP 5초 직격

**카피 (3단 명제 1차)**
```
한국 바다에서 숙성한 샴페인.

심해의 시간, 샴페인의 정점.
```

**비주얼**
- 풀스크린 영상 (8–12초 루프): 병이 수면을 지나 어둠으로 하강
- 색감: `void-bg #0A0908` · 좌측 상단 수면 관통광
- 그레인 오버레이 `opacity 0.035`

**모션**
- 영상 자동 재생 · 무음
- 헤드라인 1.2s fade-in (`gentle`), 영상 0.3s 이후 등장
- 스크롤 인디케이터 4초 후 옅은 페이드

**규칙**
- 메뉴 / 로고 외 어떤 UI 요소도 없음
- "Discover" 같은 CTA 버튼 없음 — Hero는 선언만

---

### ② SEA LOG — ★ 성공 포인트

**카피**
```
바다가 빚은 데이터.
Silent Data, Crafted by the Ocean.
```

**3중 증명 (Proof Stack)**

| 레이어 | 내용 | 역할 |
|---|---|---|
| 사진 | 입수 + 인양 실제 작업 컷 2–3장 | "정말 한다" |
| 수치 | 압력 · 수온 · 해류 (실시간) | "정밀 측정한다" |
| 메타 | 위치 · 수심 · 기간 | "추적된다" |

**실시간 데이터 (기존 `DataArchiveSection` / `DataMetricsClient` 재활용)**
- 압력: `3.97 atm` (실측 라이브)
- 수온: `11.2 °C` (실측 라이브)
- 해류: `2.34 m/s` (실측 라이브)
- 메타: `south sea, korea · depth 30 m · 180 days`
- 골드(`amber #CCAD7B`) — 단위, 메타데이터

**모션**
- 수치: 스크롤 진입 시 0 → 실측값 카운트업 (1.8s, `slow`)
- 카운트 직후 미세 떨림 ±0.02 진폭, 4s 루프 — "살아있는 바다"
- 사진: 흑백 → 채도 복원 (스크롤 진입 시 0.8s)

**레이아웃**
- 데스크탑: 사진 좌(60%) + 수치 우(40%)
- 모바일: 사진 상 / 수치 하 (단순 스택)

**감각의 닻 카피 (이 섹션의 진짜 무기)**
```
먼 훗날 잔을 기울일 때,
이 숫자가 기포의 결을 기억하게 한다.
```

> 컨설팅이 지목한 "잔 속 기포 ↔ 4기압" 신경학적 연상 회로를 작동시키는 한 줄.
> 데이터 옆에 반드시 붙는다.

---

### ③ COLLECTION — 아카이브 형식

**카피**
```
Collection.
바다가 조각한 단 한 병의 아카이브.
```

**6개 큐베 그리드 (3 × 2)**
- 각 카드: 매크로 컷(따개비·포말 자국) + `N° 003 · D40 · T6`
- 텍스트 최소 — 테이스팅 노트 · 가격 · "구매" 금지
- 호버: 보더 컬러만 `earth → amber` (0.4s, `slow`)
- 클릭: 비활성 (런칭 후 상세 페이지 연결)

**기존 `ArchiveSection` 재활용 + 카드 카피 톤만 재조정**

---

### ④ ACCESS — 두 진입로, 단일 섹션

**좌 · Ocean Cellar (일반 잠재 고객)**
```
바다의 원에 초대합니다.
[ email____________ ]
Request →
```
- 입력: 이메일 한 줄
- 완료 상태: "Access Granted" + 짧은 확인 문구
- 저장: Supabase (RLS 적용, 기존 인프라)

**우 · Partnership (B2B)**
```
파인다이닝 · 소믈리에 · 호텔 전용
[ Inquire → ]
```
- 클릭 시 인라인 폼 확장 (페이지 이동 없음)
- 필드: 업장명 · 담당자 · 이메일 · 한 줄 메시지
- 폼 확장: 0.5s height transition (`gentle`)

**기존 `OceanCircleSection` + `ProfessionalsSection` 재활용 — `s-diptych` 구조 이미 존재**

- 1줄 미니멀

### 스크롤
- Lenis (기존)
- 섹션 진입: `opacity 0→1`, `translateY 24→0` (0.8s, `gentle`)

### 반응형
| 브레이크포인트 | 동작 |
|---|---|
| ≥1280px | 12-column 풀 레이아웃 |
| 768–1279px | 8-column, Sea Log 세로 스택 |
| <768px | 단일 컬럼 |

### 성능
- LCP < 2.0s (Hero 영상 lazy + `poster` 정사진)
- First Load JS < 90KB
- Sea Log 실시간 데이터: 폴링 30s 간격 / SWR
