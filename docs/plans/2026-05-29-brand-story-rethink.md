## Context

기존 랜딩은 "분위기 → 감성 → 이미지 → 설명" 구조라 럭셔리 초창기 브랜드에 치명적인 세 약점을 가진다 — ① USP가 첫 5초에 안 꽂힘 ② '바다 숙성'이 실제 공정이 아니라 감성 컨셉처럼 보임 ③ 전환 장치가 약함. 마지막 문서(`docs/plans/2026-05-15-the-proof.md`)는 이를 선반영했으나 **코드 미반영**(현재 `src/app/page.tsx`는 옛 7섹션 유지).

이 플랜은 딥리서치(Krug/Dom Pérignon/프레스티지 희소성/**실제 해저숙성 선례**/소비자 심리/프로비넌스/K-럭셔리/비주얼 코드)를 돌리고, **럭셔리 전문가 시선 + 프레스티지 컬렉터 고객 시선** 두 관점으로 종합한 뒤, 까다로운 애호가의 **적대적 비평**으로 클리셰·신뢰성 허점을 제거한 결과다.

> ⚠️ 가장 중요한 발견부터: **이 전략의 빅아이디어는 "증명"인데, 정작 증명할 증거(입수/인양 실사·제3자 봉인·메종 확약)가 아직 없다.** 비평은 이를 "약속어음"이라 부른다. 그래서 이 플랜의 1순위 결론은 카피가 아니라 **"증거를 확보한 뒤에야 Proof를 외친다"는 실행 순서**다.

## 1. The Big Idea

> **"바다는 거짓말을 하지 못한다. 그래서 우리는 바다에 맡겼다."**

**포지셔닝:** 프랑스 NM 샴페인을 베이스로, 한국 남해의 *검증 가능한* 해양 환경에서 약 180일을 보낸 뒤 인양한다. 입수~인양 전 구간의 수온·해류·파고·파주기가 실시간 측정되어 큐베마다 단 하나의 해양 환경 로그로 남는다. **풍미의 우열을 다투지 않는다.** 어느 프레스티지 샴페인도 갖지 못한 것 — 한 병이 거쳐온 *시간의 측정된 기록* — 만을 다룬다.

> ❌ **폐기된 빅아이디어: "두 개의 떼루아 / 바다가 두 번째 떼루아다."** 비평이 직격: 듀얼 오리진은 Leclerc Briant "Abyss"가 이미 점유했고, "떼루아"는 *포도가 자라는 땅*을 뜻해 숙성 장소에 쓰면 어폐. "대화/깨어나다"식 의인화는 우리가 피하려던 오리엔탈리즘과 한 끗 차. → 채택 금지.

## 2. 왜 갖고 싶은가 (욕망의 메커니즘)

1. **측정된 단 하나의 환경 로그** — 같은 좌표·같은 계절은 두 번 오지 않는다. 차별점은 풍미가 아니라 *시간의 좌표*.
2. **음용으로 사라지지 않는 기록** — 병은 비워져도 180일 해양 데이터 아카이브는 남는다. 소비로 소멸하지 않는 소장.
3. **숨길 데이터가 없는 투명성** — 수온·해류·파고 전부 공개. 데이터가 침묵(비공개 가격)을 정당화.
4. **아무도 점유하지 않은 좌표** — 발트해·대서양·지중해는 알려졌지만 한반도 남해는 백지. 개척자의 감각.
5. **대화의 한 줄** — "이 큐베는 그해 남해 해류가 가장 거셌던 인양"이라 말할 수 있는 사회적 자본.
6. **관계로서의 접근** — Ocean Cellar Privé = 할인 멤버십이 아니라 인양 일정을 함께 아는 관계.
7. **정직한 하이브리드** — "샹파뉴에서 만들고 남해에서 기록한다"를 결함이 아니라 21세기 와인의 새 정의로.

## 4. ⚠️ 비평이 잡은 치명적 결함 (방치 시 애호가가 첫 줄에서 간파)

1. **🔴 30m vs 4기압 물리 모순.** 4atm은 수심 약 40m에서 나온다 — 30m면 약 3atm. 게다가 Abyss는 60m, Veuve Clicquot는 40m로, 30m는 해저숙성치고 *얕다*. "수압 효과"를 내세우며 가장 얕은 깊이를 고른 건 자기모순. **데이터 브랜드가 첫 숫자에서 틀리면 끝.** → *(추천: 30m 유지 + "수압" 마케팅 폐기, 어둠·수온 안정성·산소 격리로 좁힘. 또는 40m+로 깊이 재설정해 4atm과 정합.)*
2. **🔴 AOC 'Champagne' 호칭 적격성.** 샹파뉴에서 만든 와인을 한국 바다에 담갔다 빼고 재코르킹하면 법적으로 여전히 "Champagne"인가? 호칭 적격성이 깨질 수 있음. **출시 전 법무 검토 필수 게이트.** 불가 시 "샹파뉴를 떠난 시간" 같은 *정직한 새 카테고리 선언*으로 전환(어설픈 호칭 차용보다 강함).
3. **🔴 기포 물리.** 병 내부 ~6atm > 외부 4atm. "외부 수압이 기포/숙성을 만든다"는 압력차 방향을 오해한 마케팅 신화. → 오토리시스(autolysis)·격리 프레임으로.
4. **🔴 베이스 메종 무명 리스크.** Champagne Mignon Boulard는 잘 알려진 그로어가 아님. 프레스티지를 경험한 타깃은 즉시 검색하고 코웃음. → 실제 수상·평점·소믈리에 인용으로 "무명 아님"을 증명하거나, *베이스를 후면화하고 "한국 해양 환경" 자체를 주인공으로*. **둘째 메종은 확정 전까지 존재 자체를 언급 금지**(빈칸은 침묵보다 약하다).
5. **🟡 "위조 불가능한 시간 지문" 과장.** 블록체인/제3자 타임스탬프 검증 체계 없이는 거짓. 누가 측정·봉인·보증하는지 명시 필요.
6. **🟡 자산/되팔이 서사 철회.** 트랙 레코드 0인 신생 브랜드의 투자 약속은 신뢰를 깎음. → "음용으로 소멸하지 않는 기록"이라는 *비금융적 영속성*에만 집중. 세컨더리 가치는 5~10년 거래 이력 후.
7. **🟡 거인과의 비교 중단.** "Krug은 신화에 기댄다, 우리는 데이터로 증명한다"는 오만 = 신생 브랜드가 가장 빨리 미움받는 길. 경쟁 메종 언급·폄하 전면 삭제. 자기 영토만 조용히 점유.
8. **🟡 멤버십 "증인/공동 감시자" 호칭 폐기.** 감시할 일 없는 걸 감시자라 부르면 코웃음. 실물 접근권(인양 일정·데이터 열람)이라는 *사실*로.

## 5. 전략적 실행 순서 (비평의 최우선 권고)

1. **증거를 빅아이디어보다 먼저 확보.** 입수/인양 실사 영상 + 제3자(대학 해양학과·공증) 봉인 데이터 + 메종 서면 확약. 셋이 손에 들어오기 전엔 'Proof' 섹션 비공개, 그 전까진 "기록 진행 중" 티저로만. *증거 없는 proof 페이지 = Ocean Fathoms(FDA/TTB 단속) 낙인의 지름길.*
2. **두 전략을 하나로 통합.** 전문가안과 컬렉터안은 95% 동일. 약한 변주 2개 대신 검증 인프라를 갖춘 단일 전략으로.
3. **남는 에너지를 B2B 선행 신뢰 구축 로드맵에 투입** — 파인다이닝 → 럭셔리 호텔 → 소믈리에 → 국제 어워드 → 학술 발표. 리서치가 가장 강하게 권한 1년짜리 신뢰 선행(카피 미학보다 우선).

| void | `HeroSection` | 카피를 USP 직격으로 교체("두 개의 떼루아" → "샹파뉴에서 완성된 시간 / 남해에서 기록된 180일") |
| observation | `ObservationSection` | "왜 내려보냈는가" 의지 서사로. 실사 확보 전 "기록 진행 중" 톤 |
| data-archive | `DataArchiveSection` + `DataArchiveClient` + `DataMetricsClient` | **수압 항목 보류/재검토(§4-1)** + 감각의 닻 카피 + 사진 슬롯. 라이브 차트 유지 |
| archive | `ArchiveSection` | Archive No. 상단 호명 + 환경 로그 연결. 품절 미화 카피 제거 |
| the-maker | `TheMakerSection` | §6-3 메종 결정 반영. 둘째 메종 미언급 |
| ocean-circle | `OceanCircleSection` | 거래어·호칭 인플레이션 제거. 관계 언어 + 리드 수집 강화 |
| professionals | `ProfessionalsSection` | 과장 제거, B2B 로드맵 톤. 인라인 문의 |
| `s-bridge`(인라인) / `TastingSection` | — | Tasting은 직접 감각어 위반 → 제거/흡수. Bridge는 observation으로 흡수 검토 |

> 비파괴 원칙: 제거 대상은 삭제 전 백업. The Maker는 최근 커밋에서 계속 다듬던 섹션 → §6-3 결정 전 보존.
