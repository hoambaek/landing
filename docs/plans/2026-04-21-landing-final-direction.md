## 0. 한 문장 요약

**Sea Log(데이터)를 성공 포인트로 삼되, 첫 5초에 USP를 박고, 모든 섹션에 proof를 심고, Tasting 대신 "The Retrieval(귀환)"로 감정 정점을 만든다.**

> 럭셔리 마케팅의 핵심 — **'설명'하지 않고 '증명'한다.**
> Sea Log의 수치가 잔 속의 기포와 연결되는 순간, 이 랜딩은 성공한다.

## 3. 섹션별 최종 설계

### ① Hero — USP 5초 직격

**Beat 1 (정적 선언)**
```
한국 바다에서 숙성한 샴페인.

심해의 시간, 샴페인의 정점.
```

- 배경: Deep Navy/Black, 수평선 중심 미니멀
- 모션: Fade-in (서서히)
- 타이포: 헤드라인 세리프, 태그라인은 중간 대비

**Beat 2 (동적 전환 · 12초 영상)**
- 시퀀스: 샹파뉴 셀러 → 이별(바다로) → 하강 → 해저 도착
- 오버레이 없음. 자연음 또는 무음.
- Proof 시작 지점: 실제 입수 장면이 브랜드 첫 증명

**왜 이렇게:** USP ("한국 바다") 는 이 브랜드의 **유일한 차별점** — 첫 줄에 박아야 5초 이탈 방지. 태그라인이 즉시 따라붙어 "직설적이다"는 인상을 브랜드 톤으로 흡수.

---

### ② §1 해저 — 감각 + 데이터 교차 (★ 성공 포인트)

```
"바다가 빚은 데이터."
```

**3부 구조:**

```
Pression
  "수압이 기포를 다듬습니다. 더 조밀하게. 더 섬세하게."
  3.97 atm
  "이 압력이 만드는 기포를, 잔에서 확인하게 됩니다."
  연출: Champagne Gold 숫자 · 미세 진동 애니메이션 · 기포 상승 모션

Courant
  "해류가 온도를 지킵니다. 산미는 더 선명해집니다."
  11.2°C
  "첫 모금의 선명함은 이 온도에서 시작됩니다."
  연출: 수평 흐름 애니메이션

Silence
  "완전한 어둠 속에서 시간만이 일합니다."
  (데이터 없음 — 침묵에는 숫자가 없습니다)
  연출: 모든 모션 정지
```

**클로징 한 줄:** "병은 움직이지 않았습니다."

**CTA 1 (lead 수집):** 📧 `[바다의 기록, 계속 받아보기]`
**서브 링크:** 🔗 `더 깊이 보기 → /sea-log` *(Phase 2)*

**Proof:** 실제 해저 촬영 이미지 배경

**왜 이렇게:** 마케팅 피드백의 **핵심 문장**을 그대로 실현 — *"고객이 잔을 기울일 때 '이 부드러운 기포가 그 4기압의 수압 덕분이구나'라고 연상하게 만든다."* Doc 2의 "장면화" 원칙과도 충돌하지 않음(감각 → 데이터 → 감각의 교차 구조).

---

### ③ The Maker — 선택의 근거 (축소 · 1스크린)

```
지상의 탁월함, 바다에서 완성되다.

Champagne Mignon Boulard.
1911년. 4세대. 49개의 토양.

그들은 복잡함을 단순화하지 않았습니다.
그래서 우리가 선택했습니다.
```

- 연출: Embossing 느낌 로고 · 갤러리풍 여백
- 서브 링크: 🔗 `더 깊이 보기 → /makers` *(Phase 2)*

**왜 이렇게:** Doc 2의 "바다 먼저, 사람 나중" 인과 유지 + Doc 1의 "메인 서사 과부하" 문제 해결. The Maker를 **1스크린으로 압축**해서 서사는 살리되 제품 도달 시간은 줄임.

---

### ④ The Retrieval — 귀환 (★ 감정 정점 · Tasting 대체)

**원칙:** *말하지 않고 보여준다.*

**풀스크린 시네마그래프:**
- 다이버의 손 → 케이지 상승 → 수면 돌파 → 물방울 흐르는 병의 실루엣
- 자연음 (물소리 · 버블). 나레이션 없음.

**Macro-Shot 이어서:**
- 병 표면의 따개비 · 소금 결정 · 해초
- 바다가 남긴 **물증**. 캡션 최소화.

**카피 (절제):**
```
준비가 된 것들은
스스로 올라옵니다.

두 개의 떼루아를 품고, 돌아왔습니다.
```

**왜 이렇게:** Tasting("첫 모금에서 다릅니다")은 감동을 **명명**하는 언어 — 럭셔리 원칙상 약함. The Retrieval은 **이미지로 감동을 만들고 proof까지 동시 해결**. "바다 숙성이 컨셉처럼 보임" 문제(#2)도 여기서 종결.

| | Tasting (버림) | **The Retrieval (채택)** |
|---|---|---|
| 방식 | 말함 | 보여줌 |
| Proof | 없음 | 따개비 = 물증 |
| Doc 2 원칙 | 살짝 위반 | 완벽 부합 |
| 감정 정점 | 언어 | 이미지 |

---

### ⑤ Collection — 선택의 순간

```
바다가 조각한 단 한 병의 아카이브.
```

**그리드:**
- 6개 큐베 (3×2)
- Archive Nº를 **제품명보다 위에** 배치 (수집 가치 강조)
- 각 카드: 병 질감 Macro-Shot + Archive Nº + 큐베명 + 한 줄 서사
- `Édition Zéro`: `sold out` → **"바다로 돌아갔습니다"**

**큐베별 한 줄 서사 예:**
```
archive nº 001 · En Lieu Sûr
솔레라 리저브가 70%를 채웁니다.
처음이라면, 이것이 바다의 첫 인사입니다.

archive nº 005 · Atomes Crochus 3 Years Aged
40병. 3년.
더 이상의 설명은 병을 열면 납니다.

archive nº 000 · Édition Zéro
바다로 돌아갔습니다.
```

**🎯 CTA 2 (페이지 핵심 CTA):** `[컬렉션 발견하기]`

---

### ⑥ Ocean Cellar — 소속 (멤버십)

```
바다 아래, 당신의 셀러.

준비가 된 것이 올라올 때
당신이 첫 번째로 알아야 할 이유가 있다면 —

[Request Private Link]   ← CTA 3
```

- 독립된 풀스크린 섹션. 기존 레이아웃 유지.
- 혜택 나열 금지. 혜택은 멤버십 페이지 내부로.
- 폐쇄적 언어: `Access Granted` / `Request Private Link`

---

### ⑦ Partnership — 확장 (B2B)

```
이 샴페인이 열리는 순간을
함께 만들 공간을 찾습니다.

서두르지 않는 곳이면 충분합니다.

[파트너 문의하기]
```

- 독립된 풀스크린 섹션. 기존 레이아웃 유지.
- 카테고리 나열 금지(파인다이닝·호텔·셀러). 자기 규정 포기.
- 브랜드 소개서는 문의 이후 단계로 (문 앞에 두지 않음).

## 6. 필수 촬영·제작 에셋

없으면 이 방향이 작동하지 않는 것:

| # | 에셋 | 용도 | 상태 |

| 3 | **인양 장면 시네마그래프** | The Retrieval 메인 | 촬영 소스 확인 필요 |

## 8. 브랜드 원칙 체크리스트 (Doc 2 기반)

모든 카피는 이 8개 질문을 통과해야 한다.

- [ ] 설명이 아니라 **장면**인가?
- [ ] 마지막 문장이 **비어 있는가** (결론을 말하지 않는가)?
- [ ] 주어가 **"바다·시간·병"** 인가 (브랜드가 물러섰는가)?
- [ ] 독자가 이미 아는 감정에서 시작하는가?
- [ ] "프리미엄·럭셔리·특별한·최고의·혁신적인·희귀한·구매" 단어가 없는가?
- [ ] 숫자가 감정으로 연결되는가?
- [ ] Proof(물증)가 함께 있는가?
- [ ] "바다가 기억한 시간을, 당신이 마십니다."로 돌아올 수 있는가?
