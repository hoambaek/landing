## 1. 최종 판정

> **P0 2건 수정 시 배포 가능. 아래 3건은 배포 전 변호사 감수 권장.**

현 플랜은 구조·필수항목 열거·CPO/쿠키/약관 판단이 대체로 정확하나, **초안 문구 그대로 구현하면 배포 불가**. 국외이전 고지가 법정 필수 5개 항목 중 2개를 빠뜨렸고, Supabase 국내 판단이 단정이어서 처리방침 필수기재 흠결(제75조 과태료 표면)이 남는다. **P0 2건 반영 시 배포 가능 수준.**

## 2. 🔴 P0 — 배포 차단 (수정 없이는 배포 불가)

### P0-1. 국외이전 고지 필수 5개 항목 완비 (개인정보보호법 제28조의8 제2항)
위탁·보관형 국외이전은 처리방침 공개로 동의를 갈음할 수 있으나, **5개 항목 전부** 기재가 필수. 원 초안은 아래 ③·⑤ **2개 누락**.

| # | 필수 기재 항목 | Resend Inc. 기준 기재 내용 | 원안 |
|---|---------------|---------------------------|------|
| ① | 이전되는 개인정보 항목 | 이름·이메일 등 | ✅ |
| ② | 이전되는 국가·시기·방법 | 미국 / 수집 즉시 / API 전송 | ✅ |
| ③ | **이전받는 자의 명칭 및 연락처** | Resend Inc. + 연락처 명기 | 🔴 누락 |
| ④ | 이용목적 및 보유·이용기간 | 이메일 발송 / 목적 달성 시 파기 | ✅ |
| ⑤ | **이전 거부 방법·절차 및 거부 시 효과** | 예: 거부 시 접수확인·발송 메일 미제공 | 🔴 누락 |

### P0-2. Supabase "서울리전 = 국내" 판단 재확정
저장 위치가 서울(ap-northeast-2)이라도 **Supabase Inc.(미국)가 운영·지원 목적으로 원격 접근하면 국외처리·보관에 해당할 여지**. 저장 위치만 본 단정은 위험.
→ 데이터 레지던시(서울 고정 여부)·미국 본사 접근권을 계약/문서로 확인. **불명확하면 보수적으로 Supabase도 국외이전 고지 대상에 포함**하여 위 5개 항목 동일 기재. (권장 기본값 = 보수적 고지)

## 3. 🟡 P1 — 배포 전 강력 권장

### P1-1. 주류 19금 연령확인·고지 (국민건강증진법 제8조의2) — ✅ 구현 완료 (2026-07-02)
- 뮤즈드마레는 **샴페인(주류) 브랜드 홍보 표면** = 사실상 주류광고. 미성년자 묘사 금지, 온라인 표면에 **'19세 미만 이용 제한' 고지·청소년 접근제한 권고**.
- ✅ **면허 확보 확인**: 오크니는 **주류수출입업면허(나, 외국산 주류 수입·판매, 면허번호 409-2-00256, 2025-06-12)** 보유 → §8의2 "주류 수입자"로 광고 적법 자격 확보. (메모리 `reference_liquor_license`)
  - ⚠️ 면허상 상호 "주식회사 오크니 **북구점**"(광주 첨단) vs 푸터 법인정보(서울 강남) — 사업자번호 동일. 법인 주소 확정 시 본점 확인.
- ✅ **연령 게이트 구현**: 진입 시 1회 19세 확인 모달(`src/components/legal/AgeGate.tsx`, 루트 layout 마운트, localStorage 90일). "아니요" → `/exit`(로케일별) 안내 페이지. ko/en/fr 대응. 경고문구 박스 동반.
  - **방식 = 예/아니오 버튼 (2026-07-02 CEO 확정)**. 국내 브랜드 사이트 조사로 검증: 하이트진로·골든블루·카스 = 예/아니오("만 19세 이상 음주 가능한 연령입니까?" YES/NO) 표준. 페르노리카·Krug·Moët 등 수입/럭셔리는 생년월일 입력을 쓰나, CEO는 예/아니오 유지 선택. 둘 다 자가확인으로 홍보 사이트엔 합법(휴대폰 본인인증은 판매 시에만 의무).
- ✅ **경고문구 형식 보완**: 푸터 경고문구를 "경고 :" 접두 + 사각형 박스 + 판독 가능 대비로 정비(시행령 표기방법 충족).
