## 1. 관통 콘셉트 — 스크롤 = 한 병의 여정

페이지 전체가 한 병이 겪는 시간의 순서를 수행한다: **수면 → 하강 → 심해의 시간 → 인양(빛으로 상승) → 지상(소유) → 다시 바다로.**

| # | 섹션 | 여정 | 배경 토큰 | 명도 |
|---|---|---|---|---|
| S1 | Hero `void` | 수면 | `main` #C4BFBB | 라이트 |
| — | (히어로 영상) | **하강** | landing.mp4 끝 프레임 ≈ 블랙 | 라이트→블랙 |
| S2 | The Living Record `data-archive` | 심해의 시간 | `void-bg` #0A0908 → `navy-mid` | **다크** |
| S3 | The First Record (인양) | **빛으로 상승** | `navy` #0D0B09 → `warm-ivory` #ECEAE6 | **다크→라이트** ★클라이맥스 |
| S4 | Collection `archive` | 지상 — 소유 | `sand` #E8E5E1 | 라이트 |
| S5 | The Maker `the-maker` | 기원 — 두 서명 | `warm-paper` #E3E0DC (한지) | 웜 라이트 |
| S6 | Ocean Cellar Privé `ocean-circle` | **다시 바다로** | `circle-bg` #0A0D12 (블루 언더톤) | 다크 |
| S7 | Partnership `professionals` | 식탁 | `pro-bg` #F5F1E8 | 라이트 |
| F | Footer | 서명 | `void-bg` #0A0908 | 다크 |

- 명도 리듬(라이트→다크→라이트→다크)이 입수→인양→재입수의 호흡. **S3의 다크→라이트 전환이 페이지의 클라이맥스.**
- `circle-bg`의 블루 언더톤은 전체에서 S6 한 곳뿐 — "다시 바다로 내려간다"는 색의 의미 부여.
- 카피 시제 궤적: 기록되고 있다(S2) → 기록되었다(S3) → 기록을 가진다(S4) → 다음 기록을 기다린다(S6).
- ~~S1.5 서막 비트~~ **제거** — "Édition Zéro는 돌아와 있다"는 S3(인양 섹션)가 그 자체로 수행하고, 기프트 한 줄은 S4 인트로가 받는다. 별도 브릿지는 중복.

## 2. 전역 비주얼 규칙 (디자인 헌법)

1. **Amber(#CCAD7B) = 기록의 잉크.** 앰버는 오직 '기록된 것'에만 — 측정값·좌표·날짜·Archive No.·모토 서명·링크. 장식(보더 패턴·아이콘·배경)에 금지. *"금색이 보이면 그것은 기록이다"*라는 시각 언어를 페이지 전체에서 성립시킨다. 한 화면 내 앰버 요소는 1~2개로 제한.
2. **숫자는 전부 IBM Plex Mono.** 측정값·D+카운터·좌표·연도·가격. 본문·표제는 3-Font Trinity 유지(Cormorant 영문 / Noto Sans KR 한글).
3. **필름 그레인 오버레이** — 전 섹션 공통 2~2.5% 노이즈(pseudo-element, `mix-blend-mode: overlay`, GPU 합성). 브랜드 비주얼 디렉션 "촉각이 느껴지는 이미지"의 구현. The Maker 모아레 수정 때 확립한 GPU 합성 패턴 재사용.
4. **섹션 전환은 컷 금지, 그라데이션 브릿지.** 명암 여정이 끊기지 않도록 인접 섹션 배경색으로 다단 전환(기존 Sea Log→Tasting 16단계 패턴 재활용).
5. **이미지 그레이딩 통일:** 웜 블랙 기조 + 채도 -15~20%. 청록 틴트는 수중 컷(S2·S3 초반)에만 허용. 선명한 디지털 화질보다 필름 질감 — 모든 신규 에셋에 동일 LUT 적용.
6. **모토 서명 컴포넌트(공용):** *Written by the Sea.* — Cormorant Garamond 300 Italic, 15px, letter-spacing .08em, 색은 라이트 배경 `amber-muted` / 다크 배경 `amber`. S1 우하단과 Footer 중앙, 두 곳에만.
7. **모션 우선순위:** 스크롤 리빌(IntersectionObserver, 기존 ScrollReveal) + 숫자 카운팅 + S3 명도 보간, 이 셋이 전부. 산발적 마이크로 인터랙션 금지 — 클라이맥스(S3)에 모션 예산을 몰아준다. `prefers-reduced-motion` 시 전부 정적 폴백.
