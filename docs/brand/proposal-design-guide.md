## 2. Color — 제안서 전용 팔레트

브랜드 Abyssal Amber 팔레트를 제안서 맥락에 맞게 역할 분배한다.

### 배경색

| 역할 | 토큰 | HEX | 사용 |
|------|------|-----|------|
| 다크 배경 | `void-bg` | `#0A0908` | 풀블리드 임팩트 슬라이드, 커버 오버레이 |
| 뉴트럴 다크 | `navy-mid` | `#141110` | 다크 슬라이드 변형 (연속 사용 시 단조로움 방지) |
| 라이트 배경 | `sand` | `#E8E5E1` | 본문 슬라이드, 데이터 슬라이드 |
| 따뜻한 배경 | `warm-ivory` | `#ECEAE6` | 인용문, 키워드 슬라이드 |
| 페이퍼 배경 | `pro-bg` | `#F5F1E8` | 회사 정보, 크레덴셜 슬라이드 |

### 텍스트색

| 역할 | 토큰 | HEX |
|------|------|-----|
| 라이트 배경 위 헤딩 | `earth` | `#312E2A` |
| 라이트 배경 위 본문 | `earth` | `#312E2A` opacity 0.75 |
| 다크 배경 위 헤딩 | `void-text` | `#F1EFEB` |
| 다크 배경 위 본문 | `void-text` | `#F1EFEB` opacity 0.7 |

### 악센트

| 역할 | 토큰 | HEX | 사용 |
|------|------|-----|------|
| 주 악센트 | `amber` | `#CCAD7B` | 구분 바, 키워드 강조, 페이지 번호 |
| 보조 악센트 | `amber-muted` | `#b89868` | 서브 악센트 바, 캡션 강조 |

### 슬라이드 리듬

다크와 라이트 슬라이드를 교차 배치하여 시각적 리듬을 만든다.

```
[다크] 커버 → [라이트] 본문 → [다크] 임팩트 → [라이트] 데이터 → ...
```

연속 3장 이상 같은 톤 금지. 다크 슬라이드는 전체의 40~50%.

## 3. Typography — 제안서 타이프 시스템

### 폰트

| 용도 | 폰트 | 웨이트 |
|------|------|--------|
| 헤딩 (영문/프랑스어) | Cormorant Garamond | Light (300) |
| 헤딩 (한글) | Noto Sans KR | Light (300) |
| 본문 | Noto Sans KR | Regular (400) |
| 라벨/캡션 | Noto Sans KR | Regular (400) |

### 크기 체계

| 레벨 | 크기 | 행간 | 자간 | 용도 |
|------|------|------|------|------|
| Display | 64~80px | 1.1 | 0.02em | 커버 헤드라인 |
| H1 | 40~48px | 1.2 | 0.03em | 섹션 타이틀 |
| H2 | 28~32px | 1.3 | 0.02em | 서브 헤딩 |
| Body | 18~20px | 1.8 | 0.01em | 본문 (18pt 미만 금지) |
| Caption | 11~12px | 1.5 | 0.12em | 이미지 캡션, 메타데이터 (uppercase) |
| Label | 9~10px | 1.4 | 0.15em | 페이지 번호, 슬라이드 라벨 (uppercase) |

### 텍스트 배치 규칙

**수평 위치:**
- 헤딩: 좌측 정렬 기본. 임팩트 슬라이드에서만 중앙 정렬
- 본문: 좌측 정렬 고정. 중앙 정렬 금지
- 캡션/라벨: 좌측 정렬 또는 우상단 고정

**수직 위치:**
- 텍스트 블록은 슬라이드 수직 중앙 또는 하단 1/3에 배치
- 상단에 텍스트 단독 배치 금지 (이미지와 함께일 때만)

**여백:**
- 텍스트 블록 좌우 마진: 최소 80px (슬라이드 가장자리로부터)
- 헤딩과 본문 사이: 24~32px
- 본문 단락 간: 16~20px

**텍스트 한도:**
- 슬라이드당 한글 60~100자 이내 (캡션 제외)
- 한 슬라이드에 본문 단락 최대 2개
- 문장은 짧게. 명사형 종결 선호

## 4. Image Style — 이미지 디렉션

### 촬영/선정 원칙

**톤 보정:**
- 채도를 20~30% 낮춘 뮤트 톤 (muted, desaturated)
- 하이라이트는 따뜻하게 (warm highlights), 섀도는 중립~차가운 톤
- 전체적으로 필름 그레인 질감 (grain overlay 2~4%)
- 쨍한 디지털 느낌, 과포화 색상 금지

**조명:**
- 자연광 우선. 측면광 또는 역광으로 깊이감
- 강한 직사광 금지. 확산광(diffused light) 선호
- 그림자는 부드럽고 길게 — 시간의 흐름을 암시

**피사체:**
- 해저숙성 병 표면 (해양 침전물, 조개껍데기, 미네랄 결정)
- 수중 심해 (위에서 빛줄기, 하단은 완전한 어둠)
- 자연 소재 질감 매크로 (산화 금속, 석회석, 코르크, 나무결)
- 샹파뉴 포도밭 / 셀러 내부 (따뜻한 자연광, 세피아 톤)
- 남해 해저 / IoT 센서 구조물 (차가운 블루 톤)
- 병 오브제 스틸라이프 (어두운 배경, 측면 조명)

**금지 이미지:**
- 스튜디오 화보 스타일 (깨끗한 흰 배경, 인공조명)
- 사람 얼굴 클로즈업 (손, 실루엣은 허용)
- 와인잔/샴페인잔에 담긴 액체 클로즈업
- 스톡 이미지 느낌의 범용적 사진
- HDR 또는 과도한 보정

### 이미지 색온도 가이드

| 피사체 | 색온도 | 무드 |
|--------|--------|------|
| 샹파뉴/셀러/포도밭 | 따뜻함 (3200~4000K) | 골든, 세피아, 앰버 |
| 해저/수중/센서 | 차가움 (5500~7000K) | 딥 네이비, 블루, 틸 |
| 병/오브제/소재 | 중립 (4500~5000K) | 뉴트럴 웜, 자연스러운 그레이 |

## 5. Layout Patterns — 슬라이드 레이아웃

### Pattern A — Cover (커버)

```
+-----------------------------------------------+
|                         |  [img]  |   [img]    |
|    [대형 히어로 이미지]   |---------|------------|
|    (슬라이드 60%)        |  [img]  |   [img]    |
|                         +---------+------------+
|  헤드라인 (Display)      [accent bar ━━━━━━━━━] |
|  서브카피 (Body)         [accent bar]  [bar]    |
+-----------------------------------------------+
```

- 좌측: 풀하이트 히어로 이미지 (55~60%)
- 우측 상단: 2x2 보조 이미지 그리드 (40~45%)
- 우측 하단: 텍스트 + amber 악센트 바
- 오버레이: `void-bg` 40~60% 반투명 (이미지 위 텍스트 시)

### Pattern B — Full Bleed Dark (풀블리드 다크)

```
+-----------------------------------------------+
|                                               |
|   [풀블리드 다크 이미지 또는 void-bg 배경]       |
|                                               |
|        대형 헤딩 (중앙)                         |
|        "LESS IS MORE"                         |
|                                               |
|   [좌측 보조 이미지]     [우측 보조 이미지]       |
+-----------------------------------------------+
```

- 배경: `void-bg` 또는 어두운 이미지 풀블리드
- 텍스트: `void-text` 중앙 정렬
- 양쪽에 대칭 또는 비대칭 이미지 배치 가능

### Pattern C — Split (좌우 분할)

```
+-----------------------------------------------+
|                    |                           |
|   [이미지 영역]     |   섹션 라벨 (Caption)      |
|   (50~55%)        |                           |
|                    |   H1 헤딩                  |
|                    |                           |
|                    |   본문 텍스트               |
|                    |                           |
|                    |   [키워드 카드] [카드]       |
+-----------------------------------------------+
```

- 좌측: 이미지 50~55%, 풀하이트
- 우측: 텍스트 블록, 수직 중앙 정렬
- 텍스트 영역 내부 좌우 패딩: 60~80px
- 변형: 좌우 반전 (텍스트 좌, 이미지 우)

### Pattern D — Statement (임팩트 문구)

```
+-----------------------------------------------+
|              sand 또는 warm-ivory 배경           |
|                                               |
|            KEEP IT SIMPLE                      |
|              ELEGANCE                          |
|                                               |
|         본문 2~3줄 (중앙, 좁은 폭)               |
|                                               |
|              ■  ■  ■  (amber 도트)              |
+-----------------------------------------------+
```

- 배경: `sand` 또는 `warm-ivory`
- 텍스트만. 이미지 없음
- 헤딩 중앙, 본문 중앙 (max-width 600px)
- amber 장식 요소 (도트, 바, 라인)

### Pattern E — Gallery Grid (갤러리)

```
+-----------------------------------------------+
|  [이미지 1]  |  [이미지 2]  |                   |
|  (정사각형)   |  (정사각형)   |                   |
|-------------|-------------|   H1 헤딩           |
|  [이미지 3]  |  [이미지 4]  |   본문              |
|  (정사각형)   |  (정사각형)   |   캡션              |
+-----------------------------------------------+
```

- 좌측: 2x2 이미지 그리드 (60%), gap 4~8px
- 우측: 텍스트 블록 (40%), 수직 중앙
- 이미지 간 간격은 최소화 (4~8px)

### Pattern F — Closing (엔딩)

```
+-----------------------------------------------+
|              pro-bg 배경                        |
|                                               |
|            ━━━ (amber 구분선, 120px)             |
|                                               |
|            이름 · 직함                           |
|            이메일                               |
|            전화번호                              |
|            웹사이트                              |
|                                               |
|            [로고]                               |
|            법인 정보 (Caption)                   |
+-----------------------------------------------+
```

- 미니멀 중앙 정렬. 70% 이상 여백
- CTA 없음. 초대 문구 없음
- amber 구분선 하나로 상단과 분리

## 6. Accent Elements — 장식 요소

### Amber Accent Bar

```
높이: 3~4px
색상: amber #CCAD7B
너비: 80~200px (콘텐츠에 비례)
위치: 헤딩 아래 또는 이미지 하단
```

- 섹션 전환, 이미지 그리드 하단, 키워드 강조에 사용
- 슬라이드당 최대 2개
- amber + amber-muted 조합으로 2~3개 바를 나란히 배치 가능

### Dot Indicator

```
크기: 8x8px 정사각형 (border-radius: 0)
색상: earth #312E2A (라이트 배경) 또는 void-text (다크 배경)
간격: 8px
개수: 3개 고정
```

- Statement 슬라이드 하단 중앙에 장식으로 사용
- 원형이 아닌 정사각형 (브랜드 직각 원칙)

### Divider Line

```
두께: 0.5px
색상: rgba(49, 46, 42, 0.25) (라이트) 또는 rgba(241, 239, 235, 0.12) (다크)
너비: 120px (중앙) 또는 full-width
```

## 7. Image-Text Composition Rules

### 비율 원칙

| 슬라이드 유형 | 이미지 비율 | 텍스트 비율 |
|--------------|-----------|-----------|
| 커버 | 80% | 20% |
| 스토리/콘셉트 | 60~70% | 30~40% |
| 데이터/논리 | 40% | 60% |
| 임팩트 문구 | 0% | 100% (텍스트만) |
| 엔딩 | 0% | 100% |

### 이미지-텍스트 간격

- 이미지와 텍스트 블록 사이: 최소 40px
- 이미지 위에 텍스트 올릴 때: 반드시 반투명 오버레이 (`void-bg` 40~60%)
- 이미지 가장자리에서 텍스트까지: 최소 60px

### 이미지 배치 규칙

- 이미지는 슬라이드 가장자리에 밀착(bleed) 가능 — 패딩 없이 edge-to-edge
- 그리드 내 이미지 간격: 4~8px (좁은 간격으로 밀도감)
- 단일 이미지는 최소 슬라이드 높이의 70% 차지
- 이미지 위에 직접 텍스트 배치 시: 어두운 이미지만 허용 + 오버레이 필수

### 텍스트 오버레이 규칙

```css
/* 이미지 위 텍스트 오버레이 */
background: linear-gradient(
  to right,
  rgba(10, 9, 8, 0.6) 0%,
  rgba(10, 9, 8, 0.3) 60%,
  transparent 100%
);
```

- 단색 오버레이보다 그라디언트 선호
- 텍스트가 위치하는 방향에서 불투명 → 이미지 방향으로 투명

위치: 우상단 또는 우하단
폰트: Noto Sans KR Regular, 10px

## 9. Do / Don't

### DO

- 이미지를 가장자리까지 밀착 (bleed)
- 다크/라이트 슬라이드 교차 배치
- 넓은 여백 (텍스트 영역 50% 이상 비워두기)
- 뮤트 톤 이미지 + 필름 그레인
- amber 악센트 바로 시선 유도
- 한 슬라이드에 하나의 메시지
- 직각 모서리 (이미지, 카드, 도트 모두)

### DON'T

- 한 슬라이드에 이미지 5장 이상
- 텍스트로 슬라이드 가득 채우기
- 이미지에 border-radius 적용
- 밝은 이미지 위에 오버레이 없이 텍스트 배치
- 그라디언트 배경 (오버레이 제외)
- 화살표, 아이콘, 인포그래픽 과다 사용
- 표(table) 직접 배치 — 필요 시 카드형으로 변환
